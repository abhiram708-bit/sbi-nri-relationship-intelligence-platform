# sbi-nri-relationship-intelligence-platform
## 📌 Project Overview
The **SBI NRI Relationship Intelligence Platform** is an interactive banking analytics application developed using **Python**, **Streamlit**, **Pandas**, and **Altair**. It is designed to simulate an enterprise-level relationship intelligence system that helps banks identify, prioritize, and reactivate dormant NRI customers through a structured scoring framework.

The platform integrates role-based access control, customer relationship scoring, executive dashboards, customer 360° profiles, assessment and approval workflows, audit trails, and actionable business insights into a unified interface. It demonstrates the practical application of banking analytics, customer segmentation, decision support systems, and workflow automation to enhance relationship management and support data-driven decision-making in the banking sector.
